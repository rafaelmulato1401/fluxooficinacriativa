Configurar o Firebase

Para os dados sincronizarem entre o celular e o PC, este app precisa de um projeto Firebase (gratuito). Faça isso uma única vez:

  1. Acesse console.firebase.google.com e crie um projeto novo.
  2. No menu, abra Firestore Database → Criar banco de dados → modo produção.
  3. Em Regras, cole uma regra simples de leitura/escrita (posso te ajudar a travar depois).
  4. Vá em Configurações do projeto → role até Seus apps → crie um app Web.
  5. Copie o objeto firebaseConfig gerado e me envie — eu já coloco no arquivo pra você.

Assim que colocar suas credenciais no código (variável firebaseConfig no início do script), essa tela some sozinha.
